## Description

Three small pages that use plain HTML5 and JavaScript (no external libraries). Each question is in its own folder with `index.html` and `script.js`. All events use `addEventListener()` and all output uses `textContent`.

| Folder | Task | Main concepts |
|--------|------|---------------|
| `bic21203-lab4a-javascript/q1/` | Interactive Text Changer | DOM selection, `changeMessage()`, click event |
| `bic21203-lab4a-javascript/q2/` | Smart Number Validator | `checkInput()`, `if...else if...else`, input validation |
| `bic21203-lab4a-javascript/q3/` | Dynamic Number Generator | `generateNumbers()`, `for` loop, `createElement()` |

## How to run

Open the `index.html` file inside each question folder in `bic21203-lab4a-javascript` in a desktop browser. No server or installation is needed.
